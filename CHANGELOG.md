# Changelog

Изменения по релизам. Новые записи пишутся в `Unreleased`; при релизе раздел получает номер версии и дату, а его текст уходит в GitHub Release и в поле «Что нового» формы публикации.

## Unreleased

## 1.0.0 — 2026-11-27

Инструмент стал в разы легче. Это мажорная версия: часть параметров и ключей `transcript.json` удалена.

- Одна модель распознавания, GigaAM Multilingual-v2 в режиме «русский с английским»: язык выбирать не нужно. Вместе с моделью спикеров скачивается около 2 ГБ вместо 10,7. Если стояла 0.2.0 или 0.3.0, веса GigaAM заново не качаются. Во время расшифровки занято около 5 ГБ памяти.
- Видеокарта не нужна: всё считается на процессоре, torch ставится в варианте для процессора. 8,9 минуты речи модель читает за 37 с и на i9-14900K, и на RTX 4080.
- Убраны Qwen3-ASR и Granite Speech, а с ними сверка двух моделей, отметки ⚑ и параметр `--terms`: список терминов умела учитывать только Qwen3-ASR. Имена и названия модель пишет на слух, и мест, которые надо переслушать, она не называет.
- Убраны параметры `--lang`, `--terms`, `--no-check`, `--reflag`, `--config` и `-Cpu` / `--cpu` у установки. Остались путь к записи и `--out`.
- Другие языки из параметров убраны: остались русский и английский.
- `transcript.json`: у фрагмента `start`, `end`, `speaker`, `text`, `raw`; в `meta` вместо `primary` теперь `asr`, а `language`, `crosscheck`, `terms`, `flagged` и `devices` удалены.
- Установка пересобирает `.venv` с нуля, поэтому после обновления от прежних пакетов ничего не остаётся. Веса прежних моделей на диске скрипт не трогает: как их удалить, написано в README, «Обновление».
- Пакет `accelerate` больше не нужен.

## 0.3.0 — 2026-11-27

- Репозиторий открыт, лицензия — MIT вместо закрытой лицензии студии. Доступ к организации на GitHub для установки больше не нужен.
- Установка одним файлом: `install.ps1` (Windows) и `install.sh` (macOS, Linux). Файл проверяет git, ffmpeg и uv и ставит недостающее через winget или Homebrew, скачивает репозиторий на теге релиза и запускает `scripts/setup`. Повторный запуск обновляет ту же папку.
- Без видеокарты NVIDIA установщик сам выбирает вариант для процессора.
- Сама расшифровка не менялась: модели, ключи `transcript.json` и вид `transcript.md` те же, что в 0.2.0.

## 0.2.0 — 2026-11-27

- Русский: основная модель теперь GigaAM Multilingual-v2 RNNT вместо GigaAM v3. Она включается в режиме «русский с английским»: английские названия в русской речи пишет латиницей, английскую фразу посреди русской записи читает как английскую. На двух русских записях студии её слова расходились с проверочной моделью в 8,8 % и 10,7 % случаев, у GigaAM v3 — в 12,3 % и 14,1 %.
- Ещё 19 языков через ту же модель. `--lang de`, `fr`, `es`, `it`, `nl`, `pt` — с проверочной Qwen3-ASR. `--lang pl`, `ro`, `be`, `kk`, `ky`, `uz`, `tt`, `ba`, `az`, `hy`, `ka`, `tg`, `tk` — черновик без отметок. Эти языки настроены по карточке модели и на настоящих записях не проверялись.
- `--lang auto` узнаёт английский, русский, немецкий, французский, испанский, итальянский, нидерландский, португальский, польский и румынский. Остальные языки нужно называть кодом.
- В `transcript.json` два новых поля: `raw` у фрагментов GigaAM (второе чтение той же модели, слова без пунктуации: чтение с пунктуацией изредка пропускает слово) и `meta.primary_language`. Прежние ключи и вид `transcript.md` не менялись.
- Пакет `gigaam` 1.0.0. В `models.json` записаны и закреплены ещё две модели для своего `--config`: `gigaam-v4` (русский и английский, около 0,5 ГБ видеопамяти вместо 1,7) и прежняя `gigaam` (v3).
- Веса: при первом запуске после обновления скачается 1,6 ГБ (GigaAM Multilingual-v2); всего теперь около 10,7 ГБ вместо 9,6.
- Как обновиться с 0.1.0, написано в README, «Обновление». Свой файл `--config` от 0.1.0 продолжает работать.
- README: в `transcript.json` пишется только имя файла записи. В 0.1.0 код уже делал так, а в README было сказано про полный путь.

## 0.1.0 — 2026-11-06

Первая версия.

- Расшифровка записи на своём компьютере: фрагменты до 22 секунд по паузам, две модели на каждый фрагмент, спикеры S1, S2…
- Английский: Qwen3-ASR-1.7B и Granite Speech 5.0 2B. Русский: GigaAM v3 e2e RNNT и Qwen3-ASR-1.7B. Спикеры: Nemotron 3 Diarization.
- Фрагменты, где модели разошлись или пропал термин из `--terms`, отмечаются ⚑ с обеими версиями.
- `--lang en|ru|auto`, `--terms`, `--out`, `--no-check`, `--reflag`, `--config`; справка и сообщения на русском.
- Модели закреплены: коммит Hugging Face для каждой модели, SHA-256 для файлов GigaAM, проверка перед загрузкой.
- `scripts/setup.ps1` и `scripts/setup.sh` ставят точные версии зависимостей в `.venv`.
- В `transcript.json` записывается только имя файла записи, без пути: расшифровки пересылают, а путь выдаёт имя пользователя и папки клиентов.
